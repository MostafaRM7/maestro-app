# Foundation application icon

`maestro.svg` is a temporary geometric mark used to make native development,
test, and packaging builds valid during Milestone 0. It is not an approved or
irreversible Maestro logo decision.

The raster and native icon files in this directory are mechanically generated
from that SVG with:

```sh
pnpm tauri icon src-tauri/icons/maestro.svg
```

Replace the source and regenerate the set after product identity review.
